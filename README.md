### 🚀 Featured Projects

**[LLM Cost Autopilot](https://github.com/Harshini-noob/llm-cost-copilot)** — Async Python | LiteLLM | PostgreSQL | Docker | CI
An LLM gateway that routes each query to the cheapest model meeting a quality bar across Groq, Google, and OpenRouter models, using an async policy engine (economy / balanced / quality / latency), pre-call cost estimation, and budget-aware escalation. Achieved a 51.1% cost reduction (80% on simple queries) at 4.22/5 judged quality on a 30-prompt benchmark. An independent LLM judge scores every answer into Postgres so model quality is measured from real outcomes, and each routing decision explains the models it rejected. Includes an evaluation-integrity layer (config fingerprints, duplicate detection, repeated-run consistency checks), GSM8K/MMLU/MBPP adapters with SHA-256 provenance and frozen manifests, cross-provider failover, API-key auth, and a pip-installable SDK, backed by 141 automated tests.

**[RepoMentor](https://github.com/Harshini-noob/RepoMentor)** — Agentic AI | FastAPI | MongoDB | LLM Tool Calling | Python
A backend that ingests GitHub repositories, parses dependency manifests, and derives repository facts and timelines. An evidence-grounded agent answers project-specific questions by calling registered repository tools and citing its evidence. It also generates repo-grounded interview questions, evaluates answers against a rubric, tracks performance by concept, and creates lessons for missed concepts, exposed through a FastAPI API and a CLI.

**[Vayu — AI Air Quality Intelligence Platform](https://github.com/Harshini-noob/airguardian-ai)** — React | PyTorch | FastAPI | PostgreSQL | ChromaDB
A real-time AQI monitoring and forecasting platform for Chennai using 7 live CPCB/TNPCB station feeds, per-station PyTorch LSTM forecasting (RMSE 16.7–43.7), a source-attribution classifier for enforcement priority, and a bilingual Tamil/English RAG chatbot grounded in WHO/CPCB/TNPCB guidelines.

**[FinSmart — AI Financial Advisor](https://github.com/Harshini-noob/finsmart)** — React | Node.js | MongoDB | Groq Llama 3.3
A full-stack AI financial advisory platform with JWT/bcrypt auth, automated bank-statement parsing, RBI Account Aggregator (Setu) integration, and multilingual (English/Hindi/Tamil) financial insights.

**[Memory Surgeon](https://github.com/Harshini-noob)** — React | FastAPI | Cognee | Groq LLM | D3.js
A knowledge-graph-based RAG platform that ingests GitHub commit and issue history and uses Cognee's memory APIs to surface past architectural decisions and failed approaches as queryable institutional memory.
